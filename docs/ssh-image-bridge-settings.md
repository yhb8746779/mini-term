# SSH 图片桥接配置

MiniTerm 在检测到终端已进入 SSH 后，可以将单张剪贴板图片上传到远端的图片桥接目录，并发送 `Alt+V`，让 Claude Code 创建原生图片附件。

在“设置 -> SSH 图片桥接”中维护规则。每条规则仅匹配 `ssh <目标>` 的目标字符串，避免向不相关的服务器执行探测命令。

## CodeSandbox 本机沙箱模板

| 字段 | 值 |
| --- | --- |
| SSH 目标 | `4` |
| 远端图片桥接目录 | `/workspace/clipboard` |
| 就绪探测命令 | `test -x {directory}/bin/xclip` |
| 文件名前缀 | `clipboard-` |

`{directory}` 会替换为“远端图片桥接目录”。探测命令必须只在桥接可用时返回成功。

## 回退行为

- 规则未匹配、桥接不存在、探测失败或一次粘贴多张图片时，MiniTerm 上传图片到远端 `/tmp`，并输入可供 AI CLI 读取的图片路径。
- 普通 SSH 主机若没有让 Claude Code 读取图片的剪贴板桥接，无法通过配置产生原生图片附件；需要由目标环境提供等价桥接能力。
