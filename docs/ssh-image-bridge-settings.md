# SSH 图片桥接配置

MiniTerm 在检测到终端已进入 SSH 后，按“设置 -> SSH 图片桥接”中的规则处理图片粘贴。每条规则只匹配 `ssh <目标>` 的目标字符串，多个目标用逗号分隔（例如 `4,claude`），避免向不相关的服务器执行探测命令。

## 保存与切换多个沙箱配置

- 在“设置 → SSH 图片桥接”添加多个配置，或点击“复制配置”从现有配置创建独立副本，再修改名称、SSH 目标与共享目录。复制不会切换当前配置。
- 点击配置旁的“使用”，或使用主窗口顶部“图片桥接”下拉框快速切换。选择会保存，下次启动继续使用；从下一次图片粘贴生效。
- “自动匹配 SSH 目标”保留旧版本行为：按 SSH 目标从全部配置中寻找第一个匹配项。手动选择时只使用该配置，仍校验当前 SSH 目标；不匹配时回退到当前连接的 SSH 上传。
- 删除当前配置会恢复自动匹配。配置副本拥有独立 ID，修改副本不会修改原配置。
- 桥接探测缓存区分终端、SSH 连接参数和配置内容，切换配置不会误用另一配置的探测结果。

## 粘贴流程

1. **原生图片块**（单张图片）：在匹配的远端执行“就绪探测命令”，**只探测、不上传**（成功结果缓存 10 分钟）。成功后 MiniTerm 发送图片快捷键，沙箱里的 xclip 桥接当场从宿主机剪贴板取图，Claude Code 显示 `[Image #N]`。Finder / 资源管理器复制的图片文件会先写成剪贴板位图。
2. **共享目录**：探测失败或多张图片时，若规则配置了宿主机共享目录且该目录存在，图片直接写入 `<宿主机共享目录>/<子目录>`，向终端粘贴 `@<沙箱内共享目录>/<子目录>/miniterm-*.png`，全程不走 ssh。超过 24 小时的 `miniterm-*` 文件会被自动清理。
3. **ssh 上传**：以上都不可用时，另开一条 ssh 连接把图片传到远端 `/tmp`，粘贴该路径。

## CodeSandbox 本机沙箱模板

| 字段 | 值 |
| --- | --- |
| SSH 目标 | `4,claude`（Windows 别名 `4`，macOS 别名 `claude`） |
| 远端图片桥接目录 | `/workspace/clipboard` |
| 就绪探测命令 | `test -x {directory}/bin/xclip` |
| 宿主机共享目录 | Windows 默认 `H:\workspace`；macOS 填映射到 `/workspace/h-workspace` 的目录 |
| 沙箱内共享目录 | `/workspace/h-workspace` |
| 图片子目录 | `temp` |

`{directory}` 会替换为“远端图片桥接目录”。探测命令必须只在桥接可用时返回成功。

旧版本保存的出厂规则（SSH 目标仍为 `4`）会在加载配置时自动升级为 `4,claude`；用户自建的规则不受影响。

## Devbox 本机沙箱预设（v0.2.53）

| 字段 | 值 |
| --- | --- |
| SSH 目标 | `devbox` |
| 远端图片桥接目录 | `/usr/local` |
| 就绪探测命令 | `test -x {directory}/bin/xclip` |
| 宿主机共享目录 | macOS：`/Volumes/samsmobile/workspace`；其他平台留空 |
| 沙箱内共享目录 | `/workspace/h-workspace` |
| 图片子目录 | `temp` |

此预设适用于已安装 Devbox `xclip` 宿主机剪贴板桥接的沙箱。共享目录按本机映射填写；预设目录不存在时回退 SSH 上传。

新安装包含 CodeSandbox 和 Devbox 两个预设，默认按 SSH 目标自动匹配。升级仅补充一次缺少的 Devbox 预设，不覆盖已有同名 SSH 目标配置、选中的配置或 Windows 的 `H:\workspace`。用户删除预设后不会反复添加。测试版的个人项目、终端会话和登录凭据不打包进版本。

## 限制

- 宿主机共享目录必须确实映射进该沙箱，MiniTerm 只检查宿主机一侧是否存在。
- 沙箱内路径只允许字母、数字和 `/ _ - .`，避免空格截断 `@路径`。
- 普通 SSH 主机若没有让 Claude Code 读取图片的剪贴板桥接，无法产生原生图片附件，只能走路径文本。
